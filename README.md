# Project Atlas

Strategic Partnership & Hiring Proposal: **Hirav Kadikar × MProfit**.

This repository hosts the interactive, responsive strategic proposal page.

## Deployment

The project is configured for deployment to:
- **Production Domain**: [atlas.hirav.me](https://atlas.hirav.me)

## Setup & Local Development

Since this is a lightweight static single-page proposal, you can open `index.html` directly in any web browser or serve it using a local static server:

```bash
# Using python's built-in http server
python3 -m http.server 8000
```
